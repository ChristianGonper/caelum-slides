# Recortes de noticias

Se presentan cinco recortes reconstruidos con texto editable, sin publicidad ni navegación de las webs. Los titulares y bajadas de 20minutos y El Confidencial están traducidos al inglés. Las bajadas de 20minutos, Reuters y El Confidencial son resúmenes, no citas literales. DCD no lleva imagen por petición expresa. El comunicado de IAEA no contiene fotografía editorial: se conserva el primer párrafo aportado por el usuario en lugar de introducir una imagen ajena o el título genérico.
